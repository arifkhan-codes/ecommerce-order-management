# E-Commerce Order Management Platform

Full Stack E-Commerce Order Management System built with **Spring Boot**, **Spring Security**, **React.js**, **MySQL** and **JWT Authentication**.

## 🚀 Features

- Product Catalog Management
- Shopping Cart
- Order Processing & Lifecycle Management
- Payment Status Tracking
- JWT Authentication & Spring Security
- Role-based Access
- Transactional Inventory Management
- Responsive React Frontend with Tailwind CSS

## 🛠️ Tech Stack

**Backend:**
- Java 17 + Spring Boot 3
- Spring Security + JWT
- Spring Data JPA / Hibernate
- MySQL
- Maven

**Frontend:**
- React.js
- Axios
- React Router
- Tailwind CSS

## 📁 Project Structure

```
ecommerce-order-management/
├── backend/          # Spring Boot Application
└── frontend/         # React Application
```

## ⚙️ How to Run

### Backend
```bash
cd backend
./mvnw spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm start
```
